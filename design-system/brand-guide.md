# Manual de Marca — Inmobiliaria Municipal Caribe

## Paleta de colores
- Primary: #040F60 (uso: headers, fondos oscuros, botones principales)
- Secondary: #28557E (uso: botones secundarios, hovers, secciones)
- Accent: #4679A5 (uso: links, iconos activos, highlights)
- Surface: #CDD6DF (uso: fondos de sección)
- Neutrales:
  - neutral-900: #535557 (texto principal)
  - neutral-500: #7B8082 (texto secundario, iconos muted)
  - neutral-300: #CDCECE (bordes, dividers, fondos neutros)
- Semánticos:
  - success: #15803D (uso: estados de éxito, confirmaciones)
  - warning: #B45309 (uso: avisos, advertencias)
  - danger: #B91C1C (uso: errores, acciones destructivas)
- Permutación de secciones: alternar fondos blanco / surface / neutral-300 para separar bloques visuales sin agregar bordes innecesarios.

## Tipografías
- Heading: Raleway (pesos 500–800)
- Body: Raleway (pesos 400–700)
- Escala (mobile-first):
  - h1: 32px / line-height 1.2 / 700
  - h2: 24px / line-height 1.3 / 600
  - h3: 20px / line-height 1.35 / 600
  - body: 16px / line-height 1.5 / 400
  - small: 14px / line-height 1.4 / 400

## Logo
- Versión horizontal: `horizontal_*.svg` — navbar desktop, firmas
- Versión vertical: `vertical_*.svg` — footer, pantallas de login
- Versión icono (reducida): `reducida_*.svg` — navbar móvil, favicon, avatares
- Variantes de color:
  - `oscuro` (#040F60): sobre fondos claros
  - `azul` (#4679A5): contextos de acento
  - `claro` (#CDD6DF): sobre fondos oscuros
  - `gris` (#80858B): variantes neutras
  - `color` (#040F60 + #3C3C3B): uso general de marca (solo horizontal y vertical)
- Tamaño mínimo: icono 24×24px; horizontal 120px de ancho; vertical 80px de ancho
- Espacio de respeto: mínimo 16px alrededor
- Usos prohibidos: no distorsionar, no cambiar colores, no rotar, no aplicar sombras
